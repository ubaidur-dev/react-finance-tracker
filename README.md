# React Finance Tracker 
A simple but powerful personal finance dashboard. I built this to practice clean state management in React and to create a UI that actually feels premium. It tracks income, deducts expenses in real-time, and keeps a clean history of where your money is going.

### Key Features:
* **Live Calculations:** The total balance and spending amounts update instantly as you add new data.
* **Expense History:** A dedicated section that logs every transaction with an automatic date stamp.
* **Minimalist UI:** Used the Inter font and a clean color-coded system (Red/Green) for better readability.
* **Mobile Ready:** The layout is fully responsive and works smoothly on both mobile and desktop screens.

### Tech Stack:
* **Frontend:** React.js (using Functional Components and Hooks).
* **Styling:** Custom CSS with modern Flexbox layouts.
* **Icons:** FontAwesome for a professional look.

### How to Run:
Since I used the CDN approach for this version, you don't need any complex setup. Just download the files and open `index.html` in your browser to see it in action.
